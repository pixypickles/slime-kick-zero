# SLIME KICK ZERO v0.55

GitHub Pages 向けの単一 HTML ゲームです。

## v0.55 虫取り網の使いやすさ調整

迷路モードの難易度とBボタンを調整しました。

- 難易度を「ちょいむず / むずかしい / かなりむずい」に変更
- ちょいむず：ジャンパースライム2匹、焚き火2個
- むずかしい：ジャンパースライム3匹、焚き火2個、野生の蜂の巣1個
- かなりむずい：ジャンパースライム4匹、焚き火3個、野生の蜂の巣2個
- 野生の蜂の巣は一定時間ごとに、ときどき蜂を出します
- 蜂の巣へ水鉄砲を当てても蜂が出ます
- 蜂が出る難易度では、迷路内に虫取り網が1個配置されます
- 虫取り網を拾うと、迷路モード中のBボタンが虫取り網になります
- Bで網を振り、近くの蜂を捕まえられます
- 蜂を捕まえると虫取り網は使用済みになります
- 通常モード・カスタムモードではBボタンは従来どおり爆竹です
- 本編のステージ・カスタム・効果音は変更していません

`index.html` をリポジトリ直下へ置けば GitHub Pages で動かせます。

- 迷路で虫取り網を拾うと、その迷路をクリアするまで使用回数は無制限
- 網の捕獲判定を一瞬だけでなく、振っている約0.4秒間ずっと有効化
- 捕獲範囲を少し広げ、蜂が近づいたタイミングでBを押せば捕まえやすく調整
