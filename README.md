# SLIME KICK ZERO v0.41

黄色のエコースライム追加版です。

- STAGE 4を追加
- 通常スライム・ジャンパースライム・エコースライムが登場
- エコースライムへ水鉄砲が当たると「パン！」と鳴る
- 爆竹と同じ音波が発生し、ほかのスライムが振り向く
- 花モンスターは音源から逃げる
- エコースライム自身は通常どおり、水が飛んできた方向へ反応
- 得点・失点後も種類を維持して再出現

GitHub Pagesでは `index.html` と `README.md` をリポジトリ直下へ置いてください。


## v0.41

- 鳴き返しも周囲のスライムと花へ伝わります
- 無限反響を防ぐクールダウン付きです
