# SLIME KICK ZERO v0.08

「スライムに見つからず、水鉄砲で導く」ステルスアクションの基礎版です。

## この版の目的

- プレイヤーが見えないレール上を上下左右へ移動する
- 草の茂みは侵入不可
- スライム1匹が通路レール上を4方向へ歩く
- スライムは交差点で進路を選ぶ

まだ水鉄砲、発見判定、爆竹、得点は入っていません。

## 操作

- スマホ：画面下の方向ボタン
- PC：矢印キー または WASD
