# SLIME KICK ZERO v0.23

画像素材を使わず、HTML5 Canvasのコード描画だけで作ったスマホ向け試作です。

## v0.23 の変更

- 右上の外周に相手の村を配置
- 左下の対称位置に自分の村を配置
- プレイヤーは自分の村から開始
- スライムを相手の村へ導くと得点
- スライムが自分の村へ入ると失点
- プレイヤーへ触れただけでは失点しない
- 両村の対角線中央付近に出現ゲートを2つ配置
- 最初のスライムは1つ目のゲート、約18秒後の2匹目はもう一方のゲートから出現

GitHub Pagesでは `index.html` をリポジトリ直下へ置いてください。
