# SLIME KICK ZERO v0.10

水鉄砲だけを追加した確認版です。

## 今回の内容

- スライムの黒目を少し小さく調整
- Aボタンで無音の水鉄砲を発射
- 水弾は通路をかなりゆっくり進む
- 茂みに当たると消える
- スマホはAボタン、PCはJまたはSpace
- 水弾の見た目はCanvas図形のみ

この版では、水がスライムへ当たってもまだ反応しません。次段階で命中時の挙動を追加します。


## v0.10
- 上下向きの水鉄砲を身体の横へ移動
- スライム下部に接地時だけ見える半透明の濃淡を追加
- ジャンプ中は下部の濃淡が薄くなる


## v0.13
- 下向きの右腕を曲げ、水鉄砲を握って見えるよう調整
- 左向きは回転ではなく左右反転で描き、持ち手を常に下側へ固定
- 上向きは目を非表示にし、水鉄砲を身体の後ろへ描画
- 4方向の銃口位置に水弾の開始位置を一致


## v0.13
- 上向き時の腕を水鉄砲まで曲げ、手で持っているように見える描画へ修正
- 左右・下向きの描画は変更なし
