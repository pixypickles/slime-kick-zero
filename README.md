# SLIME KICK ZERO v0.22

右上の外壁を3マス開いて村前広場を追加し、その奥に相手の村を配置しました。

- 約18秒後、広場の小ゲートから2匹目が出現
- 出現後は必ず村から離れる方向へ2回小ジャンプ
- 出現直後1.8秒は得点判定なし
- 村の1マスだけが得点判定
- 画像素材は使用せず、すべてCanvas描画


## v0.25
- 村の建物を右上・左下の外周角へ移動
- 2匹目でも「!!」状態で接触すると失点
- 得点時は得点したスライムだけが消え、ほかのスライムは残る


## v0.29

- 自分の村は右隣・上隣の2マスで失点
- 両村の入口判定を対称に統一
