# スライム・キック・ゼロ - Hide & Guide

新ルール専用のアクション試作版です。

## 操作

- 上下左右：移動（斜め移動なし）
- A / J / Space：無音の水鉄砲
- B / K：爆竹

## ルール

- 草は侵入不可ブロックで、スライムの視界も遮ります。
- 水鉄砲の水はゆっくり飛び、当たったスライムは水が飛んできた方向へゆっくり進みます。
- 爆竹の音を聞くと、フィールド上のスライムが音の方向へ振り向きます。
- スライムに見つかると懐かれて追いかけられます。
- 自分の村までついて来られると失点、相手の村へ導くと得点です。
- 時間経過でスライムが追加出現します。

GitHub Pagesでは `index.html` と `README.md` をリポジトリ直下へ置いてください。
