# SLIME KICK ZERO v0.42

GitHub Pages向けの1ファイルCanvasゲームです。

## v0.42

- STAGE 6を追加
- 青紫色の変異花を追加
- 変異花へ水鉄砲を当てると、近距離へ睡眠花粉を放出
- 変異花が爆竹・エコー・オウムの音を聞くと、広範囲へ睡眠花粉を放出
- 水鉄砲由来の睡眠は約2秒、音由来の睡眠は約3秒
- 花粉範囲内の主人公とスライムが眠る
- 睡眠中は移動・水鉄砲・爆竹を使用できない
- 睡眠中の主人公とスライムにZ表示
- 変異花には連続発動を防ぐクールダウンあり

`index.html` をリポジトリ直下へ置くとGitHub Pagesで公開できます。
