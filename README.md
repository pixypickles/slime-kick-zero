# SLIME KICK ZERO v0.11

水鉄砲だけを追加した確認版です。

## 今回の内容

- スライムの黒目を少し小さく調整
- Aボタンで無音の水鉄砲を発射
- 水弾は通路をかなりゆっくり進む
- 茂みに当たると消える
- スマホはAボタン、PCはJまたはSpace
- 水弾の見た目はCanvas図形のみ

この版では、水がスライムへ当たってもまだ反応しません。次段階で命中時の挙動を追加します。


## v0.11

- 水鉄砲の4方向描画を修正
- 左右は鏡写しで持ち手を常に下側へ配置
- 下向きでは持ち手を身体の陰に隠す
- 上向きでは後ろ姿になり、目を表示しない
- 上向きの水鉄砲は身体の後ろへ描き、大部分を隠す
- 水弾をキャラクター中央ではなく銃口の先端から発射
